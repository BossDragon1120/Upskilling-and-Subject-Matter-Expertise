# Upskilling & Subject Matter Expertise

My working notes from courses, deep dives and self-directed learning in **AI, Tech and Business**. I keep them public because writing them down is how I learn, and teaching what I learn is how I find out whether I really understand it.

## Layout

```
courses/<course>/NN-<module>.md   notes from each course module
topics/<ai|tech|business>/        self-directed deep dives
glossary/<term>.md                one file per term, in plain language
templates/                        module-notes.md and term.md
```

Every note starts with a small header (`type`, `subject`, `status`, `video`) so notes can be sorted, searched and picked up automatically.

## From notes to videos

These notes are one of the two inputs to **[Little Panda Education](https://github.com/BossDragon1120/Little-Panda-Education)**, my TikTok account teaching Business, Tech and AI.

```
 this repo                                   Little Panda Education
 ─────────                                   ──────────────────────
 module notes  ─ "Teachable moments" ──▶  learning-notes-intake ──▶ Course Explainers
 glossary term ──────────────────────▶   (agent)               ──▶ AI Vocab
```

What the intake agent relies on:
- It only picks up notes marked **`status: done`** whose `video` is `none` or `idea`.
- Each bullet under **`## Teachable moments`** is one possible video. Each **glossary term** is one possible AI Vocab video.
- After a video is made, the note's `video` field moves to `scripted` → `posted`, so nothing gets made twice.
